# 워드스텝 (WordStep)

한 걸음씩 익히는 영어 단어 웹앱입니다. 화면은 **오늘 · 학습 지도 · 내 단어 · 나** 네 개의 탭으로 되어 있어요.

- 앱 주소: https://shepherdsdesk.github.io/english-practice/
- 관리자·보호자용 주소: https://shepherdsdesk.github.io/english-practice/?parent

## 나이 모드와 과정

**나 → 나이 모드**에서 고르면 화면과 과정이 함께 바뀝니다.

| 나이 모드 | 과정 | 화면 |
|---|---|---|
| 유치 | 알파벳 26자(글자마다 그림 단어 3개) + 그림 단어 60개 | 큰 글씨, 그림과 소리 중심 |
| 초등 | 기초 1,000 · 중급 500 · 고급 500 | 기본 화면 |
| 중등 | 중등 500 | 기본 화면 |
| 고등 | 고등 500 | 차분한 화면 |
| 대학 | 대학 500 | 차분한 화면 |
| 직장 | 비즈니스 300 | 차분한 화면 |
| (숨김) 신학 용어 | 개혁주의 신학 용어 200 | 관리자가 학생별로 열어 줄 때만 보여요 |

우리 단어장(관리자가 넣은 단어)은 모든 모드에서 고를 수 있습니다. 단어 목록은 수준별 대표 어휘를 골라 만든 것이며 교육부 공식 어휘 목록 자체는 아닙니다.

## 학습 방식

- **익힘 5단계:** 처음 봄 → 알아봄 → 떠올림 → 철자 → 다 외움
- **잊을 때쯤 복습:** 맞히면 1·3·7·14·30일 뒤에 다시 나오고, 틀리면 다음 날 다시 나옵니다. 하루에 한 단계씩만 올라가요.
- **문제 유형:** 새 단어 소개, 듣고 고르기, 뜻 고르기, 영어 고르기, 글자 순서, 철자 쓰기(보고 쓰기 / 첫 글자만 / 안 보고 쓰기), 말하기(브라우저 음성 인식), 예문 빈칸, 알파벳(듣고 고르기·짝 찾기·첫 글자·글자 쓰기)
- **학습 지도:** 단원마다 5단어씩 걸음을 걷고, 마지막에 **단원 시험**(10문제)을 봅니다. 80점을 넘으면 다음 단원이 열리고, 못 넘으면 틀린 단어만 연습한 뒤 다시 도전합니다.
- **문법:** 모든 과정의 문법을 6단계(이해하기 → 예문 → 고르기 → 쓰기 → 문장 만들기 → 정리)로 배웁니다. `courses/lessons-*.js`
- **영어 대화:** 상황별 대본 대화 15개. `courses/dialogs.js` (나중에 AI로 바꿀 때는 `talkPartner`만 교체)
- **단어 예문:** 기초 과정 1,000단어 모두 예문이 있습니다. `courses/examples-basic.js`

## 처음 시작과 기기 연결

- **처음 열면** "누가 쓰나요?" 화면이 나와요: 학생이에요 / 보호자예요 / 혼자 써 볼게요.
- **관리자가 코드를 발급하면** 8자리 코드와 함께 **초대 링크**와 **QR**이 나와요. 아이 폰 카메라로 QR을 찍거나 카톡으로 보낸 링크를 누르면, 코드가 자동으로 들어가고 "OOO 학생으로 연결해요"를 확인한 뒤 연결돼요.
  - 학생 링크: `.../english-practice/?code=12345678`
  - 보호자 링크: `.../english-practice/?parent&code=12345678`
- **보호자·관리자 폰**은 탭이 **우리 아이 / 쿠폰 / 공부 / 나**로 바뀌어요. '우리 아이'에서 아이별로 오늘 공부했는지, 이번 주 문제 수, 연속 일수, 쿠폰 요청을 보고 바로 허락하거나 칭찬을 보내요.
- **연결 안 된 폰**의 오늘 화면에는 "가족과 연결해요" 안내가 나오고, 연결된 폰의 나 탭에는 함께하는 가족 목록이 보여요.

## 유치(알파벳) 과정

- **글자 한 과:** 글자 이름·소리 → 그림 단어 3개 → 손가락 따라 쓰기(대문자·소문자) → 그림 보고 첫 글자 → 듣고 고르기 → 짝 찾기 → 빈칸 글자(A _ C). 한 걸음에 2글자씩 배워요.
- **반복:** 배운 글자는 잊을 때쯤 섞여서 다시 나오고, 헷갈리는 글자(b·d, p·q, m·n)를 보기로 일부러 함께 내요.
- **놀이:** ABC 노래(불 켜지는 글자 따라 부르기), 대문자·소문자 짝 맞추기 카드, 알파벳 스티커 판(배우면 스티커, 잘 외우면 금별).
- **그림 단어 단원:** 듣고 그림 고르기, 그림 보고 영어 고르기, 글자 순서.

## 가족 기능 (Firebase)

- **관리자(1명):** Firebase 콘솔에서 `members` 문서의 role을 `admin`으로 지정합니다. **나 → 관리자 메뉴**(PIN)에서 학생·보호자 코드 발급, 진도 초기화, 신학 용어 열기, 새 기기로 옮기기(진도 이어받기), 연결 해제, 우리 단어장 관리를 합니다.
- **보호자:** 8자리 보호자 코드로 연결합니다. 주간 리포트, 쿠폰 관리(사용 허락), 칭찬 한마디, 학습 보고함을 봅니다.
- **학생:** 8자리 학생 코드로 연결합니다. 진도가 클라우드에 자동 백업되고, 가족 주간 리그에 참여합니다.
- **쿠폰:** 단원 시험을 통과하면 보호자가 켜 둔 쿠폰(TV·게임·영상·놀이·늦게 자기 30분/1시간, 간식, 책, 저녁 메뉴, 용돈, 직접 만든 쿠폰) 중 하나를 고릅니다. 높은 점수(기본 95점)면 큰 쿠폰도 고를 수 있어요. 쓸 때는 보호자에게 요청이 갑니다.

Firestore 보안 규칙은 `firestore.rules`에 있습니다. 바꾼 뒤에는 Firebase 콘솔 → Firestore → 규칙에 붙여 넣고 게시하세요.

## 사진으로 단어 추가 (Gemini, 관리자 전용)

관리자 메뉴의 **AI 사진 인식 키**에 Google AI Studio에서 만든 Gemini API 키를 넣으면, **내 단어 → 사진으로 단어 추가**에서 단어장 사진을 찍어 영어 단어와 뜻을 정리하고 우리 단어장에 넣을 수 있습니다.

- 키는 관리자 기기의 브라우저에만 저장되고 저장소에는 올라가지 않습니다.
- Gemini API 약관상 18세 미만이 쓰는 앱에는 넣을 수 없어서, 학생 화면에서는 AI를 부르지 않고 관리자 화면에서만 씁니다.
- 무료 등급은 올린 내용이 Google의 서비스 개선에 쓰일 수 있으니, 이름·얼굴이 나오지 않게 단어 부분만 찍으세요.
- Google Cloud 콘솔에서 키에 HTTP 리퍼러 제한(`shepherdsdesk.github.io/*`)을 걸어 두면 더 안전합니다.

## 파일 구성

- `index.html` · `css/app.css` — 화면 틀과 디자인(유치·기본·차분 테마, 태블릿 레이아웃)
- `js/core.js` — 저장, 과정, 학습 엔진(익힘 단계·간격 복습), 소리, Firebase
- `js/ui.js` — 아이콘, 마스코트 새싹이, 화면 전환
- `js/learn.js` — 학습 세션, 문제 유형, 단원 시험, 쿠폰 고르기, 문법, 대화
- `js/screens.js` — 오늘, 학습 지도, 내 단어, 나, 리그, 기기 연결
- `js/admin.js` — 관리자, 보호자 리포트·쿠폰, Gemini 사진 인식, 시작
- `js/basic.js` · `courses/*.js` — 과정 데이터
- `sw.js` — 오프라인 지원(인터넷이 되면 항상 최신 파일)
